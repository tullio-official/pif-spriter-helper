<h2><picture><source media="(prefers-color-scheme: dark)" srcset="assets/readme/unsprited-finder-dark.svg"><img src="assets/readme/unsprited-finder-light.svg" width="214" height="24" alt="Unsprited Finder"></picture></h2>

A tool that shows random unsprited fusions for inspiration. It has a bunch of filters to help you narrow down your search.

<a href="https://tullio-official.github.io/pif-spriter-helper/unsprited-finder/"><picture><source media="(prefers-color-scheme: dark)" srcset="assets/readme/btn-unsprited-finder-dark.svg"><img src="assets/readme/btn-unsprited-finder-light.svg" width="284" height="48" alt="Open Unsprited Finder"></picture></a>

<h2><picture><source media="(prefers-color-scheme: dark)" srcset="assets/readme/palette-library-dark.svg"><img src="assets/readme/palette-library-light.svg" width="192" height="24" alt="Palette Library"></picture></h2>

A library of all palettes used to sprite a Pokémon, including its base sprites and every fusion where it's the head.

<a href="https://tullio-official.github.io/pif-spriter-helper/palette-library/"><picture><source media="(prefers-color-scheme: dark)" srcset="assets/readme/btn-palette-library-dark.svg"><img src="assets/readme/btn-palette-library-light.svg" width="272" height="48" alt="Open Palette Library"></picture></a>
